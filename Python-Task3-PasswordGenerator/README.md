# Advanced Random Password Generator

A secure password generator built using Python Tkinter and SQLite.

## Features

- Secure password generation
- Password strength analysis
- Copy to clipboard
- Password history storage
- Modern GUI

## Technologies Used

- Python
- Tkinter
- ttkbootstrap
- SQLite
- Pyperclip

## Installation

pip install -r requirements.txt

## Run

python password_generator.py
